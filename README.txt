DOPPELGÄNGER PROTOCOL — PROJECT DOSSIER

UPLOAD
1. Unzip this package.
2. Upload the CONTENTS of the Doppelganger_Protocol_Project_Dossier folder (index.html and assets/) to a folder on your web server, e.g. /doppelganger-protocol/.
3. Open https://your-domain.com/doppelganger-protocol/

Keep the assets folder alongside index.html. No build step, JavaScript framework, or server-side application is required.

The Vimeo video is embedded from Vimeo and requires an internet connection; check its privacy/embed settings if it does not play.

The image assets are project artwork and are not licensed for reuse by visitors.

SEARCH INDEXING: The HTML contains noindex, nofollow, noarchive. robots.txt permits crawling so search engines can read the noindex directive. This does not make the public GitHub repository private or prevent direct access.
